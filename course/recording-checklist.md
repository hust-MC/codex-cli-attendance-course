# 录课检查清单

## 录制前

- 确认固定演示日期和演示数据。
- 删除本地临时数据库，从初始化脚本重新生成。
- 跑通测试和一键验收脚本。
- 准备当前章节和上一章节两个快照。
- 准备现场 Prompt 和失败兜底 Prompt。
- 打开终端、浏览器、数据库查看工具和代码编辑器。
- 确认页面缩放、终端字号和浏览器书签栏适合录制。

## 录制中

- 先说明本节要交付的可见结果。
- 展示修改前的状态和验收命令。
- 粘贴完整 Prompt 后解释关键约束。
- 保留真实报错，不要立即剪掉。
- 修复后重新运行同一验收命令。
- 结尾展示最终结果并口述下一节衔接。

## 录制后

- 保存本节 Prompt。
- 保存命令输出、错误日志和测试结果。
- 保存页面截图和关键代码截图。
- 标注本节可独立成立的知识点。
- 记录下一节需要承接的状态。
- 验证按本节 Prompt 能在干净快照上复现。

## 每章最低验收

- 有一个可运行结果。
- 有一次真实问题或边界讨论。
- 有一个可复用 Prompt。
- 有一个可以截图展示的证据。
- 有一个连接到最终项目的业务价值说明。
