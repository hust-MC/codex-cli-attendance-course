# 录制用 Prompt 归档

每章两版 Prompt：一版给 Codex CLI（能读仓库、能读 `AGENTS.md`），一版给 DeepSeek（只吃你粘贴进去的文字）。

## 为什么每个模型都要单独写

| | Codex CLI | DeepSeek |
|---|---|---|
| 能读仓库文件 | 能，直接 `AGENTS.md` 生效 | 不能，内容必须粘进 Prompt |
| Prompt 长度 | 规范越短越好 | 必须自带关键约束 |
| 适合演示 | 规范沉淀、长短对比 | 拆步骤、先出计划再写码 |

所以同一章里，Codex 版通常更短，DeepSeek 版更啰嗦。这个差异本身就是第四章要讲的东西。

## 目录

| 章节 | 文件 | 演示重点 |
|---|---|---|
| 第三章 | `ch03/codex.md`、`ch03/deepseek.md` | 没有规范文件时，Prompt 必须自带约束 |
| 第四章 | `ch04/codex.md`、`ch04/deepseek.md` | 有规范文件后，Prompt 只剩本轮增量 |

## 使用约定

- 这些 Prompt 是**起点**，不是标准答案。课程本身就是来回打磨的过程。
- 每次实际录制后，把真实用过的 Prompt 和结果回写到 `build-log/<章节>/prompt.md`。
- Prompt 里不要写「请严格按照规范执行」这类没有信息量的话，把可检查的约束写出来。
- 每次只交代本轮范围，并且写清楚「这轮不做什么」。
