| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | 项目基本信息 |

| POST | `/api/employees` | 新增员工 |
| GET | `/api/employees` | 员工列表 |
| GET | `/api/employees/<id>` | 员工详情 |
| PUT | `/api/employees/<id>` | 修改员工 |
| DELETE | `/api/employees/<id>` | 删除员工 |
| POST | `/api/checkins/in` | 签入 |
| POST | `/api/checkins/out` | 签出 |
| GET | `/api/checkins` | 查询员工日期打卡记录 |
