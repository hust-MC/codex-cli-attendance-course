# 第二章 2.4：20 分钟跑通

## 用户实际 Prompt

```text
在当前目录创建一个 Flask 项目，技术栈：Python + Flask + SQLite。
项目名：指尖打卡 —— 员工考勤系统。

以下是目前需要开发的功能
- 员工管理：增删改查员工信息（姓名、部门、工号）
- 签入（上班打卡）：员工签到，记录打卡时间
- 签出（下班打卡）：员工签退，记录签退时间


约束：
- 严格三层结构：routes/ 放路由，services/ 放服务，models/ 放数据
- 数据库用 checkin.db 命名
- 响应格式：{"code": 200, "message": "...", "data": ...}
- 错误码：400 参数错误，404 找不到，500 服务器错误
- 必须用中文注释
- Python 函数名用 snake_case，类名用 PascalCase
- 每行不超过 120 字符
- 禁止在路由层直接写 SQL，必须经过 service 层
- commit 格式：type: 描述（type 只能是 feat / fix / chore / docs）
- 完成后自己 curl 自测一遍
```

## 本轮执行边界

- 只实现员工、签入和签出。
- 不实现请假、加班、考勤核算、异常和报表。
- 不添加前端页面。
- 不提前引入 AGENTS.md，第四章再讲。
